How to build and run the WASM server
=====================================

Prerequisites:
  - Emscripten SDK at ~/Projects/emsdk (version 3.1.56, required by Qt 6.8)
  - Qt 6.8.3 WASM kit at ~/Qt/6.8.3/wasm_multithread/
  - Qt 6.8.3 host kit (Linux: ~/Qt/6.8.3/gcc_64/, macOS: ~/Qt/6.8.3/macos/)
  - cmake (Linux: apt install cmake, macOS: brew install cmake)
  - python3 (for aqtinstall and the dev server)
  - git

0. Install prerequisites (one-time setup):

   a) Install Emscripten SDK 3.1.56:

      cd ~/Projects
      git clone https://github.com/emscripten-core/emsdk.git
      cd emsdk
      ./emsdk install 3.1.56
      ./emsdk activate 3.1.56
      source ./emsdk_env.sh
      em++ --version              # verify it works

   b) Install the Qt 6.8.3 WASM kit + host kit. Use EITHER the official Qt
      Maintenance Tool (GUI, recommended if Qt was installed via the official
      online installer) OR aqtinstall (CLI, no Qt account needed). You need
      two components: the "WebAssembly (multi-threaded)" kit and a matching
      host kit (Desktop gcc 64-bit on Linux, macOS on macOS).

      IMPORTANT: install the MULTI-THREADED WASM kit (wasm_multithread), NOT
      wasm_singlethread. The FFT runs multithreaded in the browser and the
      build (CMakeLists.txt) compiles with -pthread, which requires this kit.

      Option 1 - Qt Maintenance Tool (GUI):

        Launch it:
          # macOS:
          open ~/Qt/MaintenanceTool.app
          # Linux:
          # ~/Qt/MaintenanceTool

        Sign in with your Qt account, choose "Add or remove components",
        expand Qt -> Qt 6.8.3 and tick:
          - WebAssembly (multi-threaded)
          - your host kit, if not already installed
            (Linux: "Desktop gcc 64-bit"; macOS: "macOS")
        then Next -> Install. The tool installs to ~/Qt/6.8.3/wasm_multithread
        (and the host kit) and sets execute permissions correctly, so the
        chmod step below is NOT needed with this option.

      Option 2 - aqtinstall (CLI):

        pip3 install aqtinstall

        # WASM kit (same on all platforms)
        aqt install-qt all_os wasm 6.8.3 wasm_multithread --outputdir ~/Qt

        # Host kit (must match your OS — required for cross-compilation)
        # Linux:
        aqt install-qt linux desktop 6.8.3 gcc_64 --outputdir ~/Qt
        # macOS:
        # aqt install-qt mac desktop 6.8.3 --outputdir ~/Qt

        # This installs the WASM kit to ~/Qt/6.8.3/wasm_multithread/
        # and the host Qt to ~/Qt/6.8.3/gcc_64/ (Linux)
        # or ~/Qt/6.8.3/macos/ (macOS).

        # Fix execute permissions (aqtinstall does not set them — required,
        # otherwise qt-cmake fails with "Permission denied"):
        chmod +x ~/Qt/6.8.3/wasm_multithread/bin/*
        # Linux host kit:
        chmod +x ~/Qt/6.8.3/gcc_64/bin/*
        # macOS host kit:
        # chmod +x ~/Qt/6.8.3/macos/bin/*

1. Rebuild (only needed after code changes):

   source ~/Projects/emsdk/emsdk_env.sh
   cd ~/Projects/ft
   rm -rf build_wasm
   mkdir build_wasm && cd build_wasm
   # Linux:
   ~/Qt/6.8.3/wasm_multithread/bin/qt-cmake \
       -DQT_HOST_PATH=$HOME/Qt/6.8.3/gcc_64 \
       -DQT_HOST_PATH_CMAKE_DIR=$HOME/Qt/6.8.3/gcc_64/lib/cmake ..
   # macOS (replace gcc_64 with macos):
   # ~/Qt/6.8.3/wasm_multithread/bin/qt-cmake \
   #     -DQT_HOST_PATH=$HOME/Qt/6.8.3/macos \
   #     -DQT_HOST_PATH_CMAKE_DIR=$HOME/Qt/6.8.3/macos/lib/cmake ..
   cmake --build .
   cp ~/Qt/6.8.3/wasm_multithread/plugins/platforms/qtloader.js .
   cp ~/Qt/6.8.3/wasm_multithread/plugins/platforms/qtlogo.svg .
   sed -e 's/@APPNAME@/ft/g' \
       -e 's/@APPEXPORTNAME@/createQtAppInstance/g' \
       -e 's/@PRELOAD@//g' \
       ~/Qt/6.8.3/wasm_multithread/plugins/platforms/wasm_shell.html > ft.html
   ln -sfn ~/Projects/ft/EXAMPLE_IMAGES images

2. Start the server:

   cd ~/Projects/ft/build_wasm
   # Linux:
   hostname -I | awk '{print $1}'
   # macOS: ipconfig getifaddr en0

   # Optional, Linux only, if ufw is installed/enabled and you need
   # access from other machines on your network:
   # sudo ufw allow 8080/tcp

   # The multithreaded build needs SharedArrayBuffer, which the browser only
   # exposes on a cross-origin-isolated page (COOP/COEP headers). The stock
   # "python3 -m http.server" does NOT send them — use the bundled server:
   python3 ~/Projects/ft/serve_wasm.py 8080

3. Open in browser:

   Local:   http://localhost:8080/ft.html
   Network: http://<your-ip>:8080/ft.html

   Verify threads are active in the JS console:
     crossOriginIsolated         -> true
     typeof SharedArrayBuffer    -> "object"

4. Stop the server:

   Press Ctrl+C in the terminal, or:
   # Linux: fuser -k 8080/tcp
   # macOS: lsof -ti:8080 | xargs kill -9
